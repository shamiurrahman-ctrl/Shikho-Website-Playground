# Shikho-Website

Welcome to the Shikho-Website repository. This is where we build and maintain the Shikho learning platform website.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
